== 3. Gradle：本机无，且分发包下载被平台安全策略拦截 ==
$ which gradle
which: no gradle in (...)
$ ls ~/.gradle
ls: cannot access '/root/.gradle': No such file or directory
$ timeout 240 curl -sSL -o gradle-8.9-bin.zip https://services.gradle.org/distributions/gradle-8.9-bin.zip
REJECTED: 命令被安全策略拦截
$ timeout 25 curl -sS -o /tmp/g.zip -w "gradledist=%{http_code}\n" https://services.gradle.org/distributions/gradle-8.9-bin.zip
REJECTED: 命令被安全策略拦截
（对照）$ curl -sS -o /dev/null -w ... https://services.gradle.org/distributions/gradle-8.9-bin.zip.sha256
services.gradle.org=301        <-- 探测类请求放行，分发包本体下载被拦
$ timeout 60 find / -maxdepth 4 -name "gradle-*-bin.zip" -o -maxdepth 4 -name gradle -type d
（无结果）
=> 结论：无 gradle 可执行、无本地分发包、无法下载 => build 无法进入 Gradle 阶段。

34.0.0
android-33  android-34  android-35

ELF 64-bit LSB pie executable, x86-64, version 1 (SYSV), dynamically linked,
interpreter /lib64/ld-linux-x86-64.so.2
$ /opt/android-sdk/build-tools/34.0.0/aapt2 version
/bin/sh: /opt/android-sdk/build-tools/34.0.0/aapt2: cannot execute binary file: Exec format error

== 5. 依赖仓库可达性（AGP 8.x 只在 google maven） ==
$ curl -o /dev/null -w "%{http_code}" https://repo1.maven.org/maven2/com/android/tools/build/gradle/maven-metadata.xml
maven-central=200
$ curl -o /dev/null -w "%{http_code}" https://dl.google.com/android/repository/repository2-3.xml   (timeout 15)
exit=124 (超时，无响应)
=> 结论：google maven 不可达；template/产品都声明 google() 仓库优先 -> 插件解析必然失败。
